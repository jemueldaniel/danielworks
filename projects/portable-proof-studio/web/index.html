What this demonstrates—and what it does not

Actual persistence

Stored in an on-disk SQLite database. Restart the local server and reuse your test workspace to inspect saved data.

Replay safety

Repeated mutation keys return the same committed result; changed intent conflicts and workspace isolation is checked before replay.

Explicit limits

Local-only guest bearer token, bounded documents/workflows and synchronous four-step execution. No durable background job queue, true user accounts or external tools.
