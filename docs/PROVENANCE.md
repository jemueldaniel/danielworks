# Source, authorship and redistribution boundaries

The public candidate consists of the preserved AI-assisted examples and fresh generic integration work using synthetic data. Private source was inspected only to select historically supported techniques; no private implementation, private grammar, internal protocol extension, source history, prompt, dataset or business architecture was copied, renamed or translated into this candidate. Detailed private provenance is excluded. This is the coordinator’s source-selection account, not independent certification of every historical source or ownership claim; whole-package review remains incomplete.

Repository access is not proof of ownership or sole authorship. These demonstrations do not claim employment history, real users, model-scale expertise, performance superiority or deployment. The coordinator performed implementation and self-review. A separate reviewer inspected the exact eight Rust project files without changing them or running tests and found no blocking defect; two low-severity observations remain explicitly documented. This is independent static review, not independent execution or certification of all historical work. Full-package review status is maintained in [REVIEW_STATUS.md](REVIEW_STATUS.md).

Third-party packages are obtained separately using `package-lock.json`; their licenses continue to apply. `node_modules`, built bundles and browser binaries are not vendored in the source archive. The normal build produces a local React/dependency bundle; its licenses must still be honored if that output is redistributed. Python, SQLite and Node also retain their own licenses. See [dependency notes](DEPENDENCIES.md).

No blanket license or relicense of existing repository material was added. The owner authorized public source publication. No umbrella software license was selected or invented; publication authorization is not a blanket relicense of code or third-party dependencies. Any additional grant of reuse rights remains an owner decision, distinct from this already-authorized publication. Code with uncertain source ownership was not selected for copying. No Git history, website assets, form integrations, credentials, internal paths, private inventory or CI workflow is included in this candidate.

Synthetic tests are not customer evidence. Reopening a database or killing a worker is not a power-loss test. Local HTTP is not a deployed service. A small ranking score is not a model benchmark. A dependency audit with zero known findings is not proof that software is secure.
