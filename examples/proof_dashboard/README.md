# Engineering Proof Dashboard

A new original responsive, searchable frontend for public engineering references. All cards link exclusively to source already published in `jemueldaniel/danielworks`. No private repository or customer data is read or embedded.

## Run

From this directory run `python -B -m http.server 4342 --bind 127.0.0.1` and open `http://127.0.0.1:4342`.

Run deterministic model tests with `node --test examples/proof_dashboard/test_data.mjs` from the repository root. The interface has accessible labels, dark/light mode, source links, responsive cards and local-only filtering. No server API, credentials, external telemetry or private company code is required.

The references demonstrate independently inspectable educational implementations. They do not prove authorship of separate private systems, commercial licensing, production readiness or complete accessibility compliance. Browser acceptance is a separate qualification.
